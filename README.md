# Little Day

The Little Day family clock and daily routine app. The HTML entry point is `index.html`.

## Assets
Upload the matching files from the Little Day assets package into `assets/` before deploying. Empty placeholder assets are not used.

## Publish with GitHub Pages
Open Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save. Once real asset files are uploaded, the site should be available at `https://thatsmetho.github.io/Littlewonderfulday/`.

Note: alarms in a browser may not fire when the device is locked, asleep, or the browser is suspended.
